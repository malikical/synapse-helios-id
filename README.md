## 🌟 1. Visi & Ikhtisar Platform

**SYNAPSE HELIOS ID** adalah platform arsitektur kognisi fullstack monorepo/single-service yang dirancang untuk membedah, mengklasifikasikan, dan mengeksplorasi perkembangan **Artificial Intelligence (AI)** paling mutakhir dalam Bahasa Indonesia yang berbobot editorial arsitektural.

Menggabungkan estetika *cyber-architectural* klasik (Obsidian `#050505`, Accent Cyber Cyan `#00f3ff`, blueprint grid crosshair, dan canvas harmonik 3D) dengan mesin inferensi kognitif interaktif, platform ini menyajikan taksonomi model penalaran mendalam (*Reasoning Models*), model fondasi omni-modal, sistem multi-agen otonom, simulator dunia spasial, perbandingan arsitektur transformator vs sparse MoE vs linear SSM, serta peta jalan menuju AGI.

## 🧩 2. Taksonomi AI Komprehensif (6 Sektor Kunci)

Platform ini mengintegrasikan dataset taksonomi yang dapat diakses langsung via UI interaktif dan REST API (`GET /api/ai-types`):

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        SYNAPSE HELIOS AI TAXONOMY HIERARCHY                            │
├──────────────────────────┬──────────────────────────┬──────────────────────────────────┤
│ 01. REASONING & CoT      │ 02. OMNI-MODAL FRONTIER  │ 03. AUTONOMOUS AGENTIC SWARMS    │
│ • Hidden Chain-of-Thought│ • Native Tokenization    │ • ReAct Cognitive Loop           │
│ • Test-Time Compute PRM  │ • Real-time Audio-to-Audio│ • Computer-Use & MCP Protocol   │
│ • OpenAI o1/o3, DeepSeek │ • 2M-10M Context Window  │ • Multi-Agent Swarms & Sandboxes │
├──────────────────────────┼──────────────────────────┼──────────────────────────────────┤
│ 04. WORLD & MEDIA MODELS │ 05. ARCHITECTURE MATRIX  │ 06. AGI ROADMAP & ALIGNMENT      │
│ • Diffusion Transformers │ • Dense vs MoE vs Mamba  │ • 5-Level AGI Taxonomy           │
│ • Flow Matching ODE      │ • KV-Cache Optimization  │ • Constitutional AI (RLAIF)      │
│ • Sora, Veo 2, Hailuo    │ • Linear Time O(N) Scan  │ • Mechanistic Interpretability   │
└──────────────────────────┴──────────────────────────┴──────────────────────────────────┘
```

1. **Model Penalaran Mendalam & Komputasi Inferensi (Reasoning & Test-Time Compute):**
   - Skalabilitas komputasi saat inferensi (*Test-Time Scaling Laws*).
   - *Hidden Chain-of-Thought (CoT)* dengan *Process Reward Models* (PRM) untuk evaluasi langkah logika atomik.
   - Pionir: OpenAI o1/o3, DeepSeek-R1, QwQ.

2. **Model Fondasi Omni-Modal Lintas Domain:**
   - Representasi laten terpadu tanpa *pipeline* terpisah (Native Multimodal Tokenization).
   - Pemrosesan video, citra, audio-ke-audio waktu-nyata (<250ms), dan teks.
   - Pionir: Gemini 2.0 Flash/Pro, Claude 3.7 Sonnet, GPT-4o.

3. **Sistem Agen Otonom & Orkestrasi Multi-Agen:**
   - Siklus persepsi dan aksi mandiri (*ReAct Loop*).
   - Integrasi *Model Context Protocol* (MCP) dan manipulasi desktop langsung (*Anthropic Computer Use*).
   - Swarm multi-agen hierarkis (LangGraph, CrewAI, AutoGen).

4. **Model Dunia & Media Generatif Spasial (World Models):**
   - *Diffusion Transformers (DiT)* & *Rectified Flow Matching*.
   - Simulasi dinamika fisika, inersia, kontinuitas spasial-temporal objek, dan sintesis audio multi-track (Sora, Veo 2, Hailuo, Suno v4).

5. **Fondasi Arsitektural Komputasi AI:**
   - Perbandingan komputasional: Dense Attention ($\mathcal{O}(N^2)$) vs Mixture-of-Experts (MoE, e.g. DeepSeek-V3) vs State Space Models ($\mathcal{O}(N)$ Mamba 2 & Griffin).
   - Analisis efisiensi memori KV-Cache dan throughput token per detik.

6. **Narrow AI (ANI) menuju Peta Jalan AGI & Penyelarasan:**
   - 5 Tingkat Kematangan Kognisi AGI (Emerging $\to$ Competent $\to$ Expert $\to$ Virtuoso $\to$ Superhuman).
   - Protokol Keselamatan: *Constitutional AI* (RLAIF), *Mechanistic Interpretability* (Sparse Autoencoders), dan *Scalable Oversight*.

## 💻 4. Terminal Interaktif Synapse

Terminal interaktif bawaan terhubung langsung ke endpoint `POST /api/terminal` dengan 3 mode operasi:
- **Sintesis Kreatif**: Jawaban reflektif berwawasan filosofis & kognitif.
- **Arsitek Kode**: Sintesis kode komputasi tensor, CUDA kernels, Python attention, dan arsitektur sistem.
- **Analisis Mendalam**: Evaluasi multidimensi, kalkulasi kompleksitas komputasi, dan metrik alignment.

## 🚀 5. Panduan Instalasi & Menjalankan Aplikasi

### Prasyarat:
- Python 3.10+ (Direkomendasikan Python 3.12+)
- Git

### Menjalankan Secara Cepat:
```bash
# 1. Clone repositori
git clone https://github.com/malikical/synapse-helios-id.git
cd synapse-helios-id

# 2. Jalankan skrip runner otomatis
./run.sh
```

Atau jalankan langkah manual:
```bash
# Buat Virtual Environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependensi
pip install -r requirements.txt

# Jalankan pengujian unit
pytest -v

# Jalankan server
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Akses antarmuka web di: **`http://localhost:8000`**
Dokumentasi interaktif OpenAPI (Swagger): **`http://localhost:8000/docs`**

## 🛠️ 7. Dokumentasi REST API

- **`GET /api/ai-types`**: Mengembalikan seluruh taksonomi AI 6 kategori beserta benchmark dan formulasi matematika.
- **`GET /api/ai-types/{type_id}`**: Mengambil rincian mendalam jenis AI tertentu.
- **`GET /api/languages`**: Mengembalikan daftar bahasa pemrograman AI, logo resmi SVG/PNG, metrik efisiensi, dan contoh kode.
- **`GET /api/languages/{lang_id}`**: Mengambil detail bahasa pemrograman dan arsitektur runtime.
- **`POST /api/terminal`**: Memproses kueri kognitif multi-mode (`creative`, `code`, `analysis`).
- **`GET /api/health`**: Memeriksa status kesehatan node dan klaster.
